# Unity Survival Shooter Game

## Overview

A survival shooter game developed using Unity as part of an AI418 Human-Computer Interaction project.

The project focuses on designing an interactive and user-friendly game environment while integrating intelligent agents, dynamic gameplay mechanics, navigation systems, animation, and user interface components.

## Features

* Player movement and animation
* Shooting and firing mechanics
* Player health system
* Enemy AI behavior
* NavMesh-based enemy navigation
* Enemy animation and state machines
* Multiple enemy types
* Dynamic enemy spawning through an enemy manager
* Player scoring system
* Game Over screen with UI, animation, and code
* Interactive and user-friendly game environment
* Intelligent agent integration

## Intelligent Agent

An intelligent enemy agent was implemented using Unity's NavMesh system to enable autonomous navigation and behavior.

The project also includes enemy state machines, animations, and behavior logic to create dynamic interactions between the player and enemies.

## Technologies
